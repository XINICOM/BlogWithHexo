# 安装

## 必要组件

```ps1 | lang:PowerShell
scoop install neovim git gcc ripgrep fd unzip tree-sitter luarocks
```

## 配置

### 直接使用我的配置

[NeoVim Config](https://github.com/XINICOM/nvim.git) 放到 `$env:LOCALAPPDATA\nvim\` 下

### 一般配置

可以参考官网 [LazyVim Installation](https://www.lazyvim.org/installation) 的步骤，这个步骤非常全面
