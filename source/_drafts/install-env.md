# Torch

## 仅 CPU 版本

推荐使用 [Torch 官网](https://pytorch.org/get-started/locally/) 安装

## GPU 加速版

1. 升级 GPU 驱动
2. 安装 CUDA Toolkit
3. 安装 Torch 对应的 CUDA 版本
4. 使用 `nvidia-smi` 命令测试
